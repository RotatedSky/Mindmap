# 思绪图工具

纯前端思绪图工具。一个 HTML 页面 + 原生 JS + 本地内置 KaTeX（数学公式渲染），无网络依赖，无需安装任何框架，桌面与手机浏览器均可使用，支持离线（PWA）。

## 运行方式

**直接打开**：双击 `index.html` 即可使用（注意：直接打开时 PWA 离线功能不生效）。

**本地服务器（推荐，启用 PWA）**：

```bash
npx serve .
# 或
python -m http.server 8080
```

然后访问 `http://localhost:8080`，手机可通过同一局域网访问（或用静态托管部署到任何地方）。

## 功能一览

### 创建与编辑
- 图形化交互：点击节点选中，双击 / F2 编辑文字（`Enter` 提交，`Shift+Enter` 换行）
- `Tab` 添加子节点，`Enter` 添加兄弟节点，`Delete` 删除（含子树）
- 拖拽节点到目标节点上，调整父子关系（树形模式）
- 自由布局模式：节点可拖到任意位置（实时跟手，连线同步更新）
- 节点文字支持多行与自动换行（长文本按宽度自动软折行）
- 节点内支持 LaTeX 公式：在文字中书写 `$...$`（如 `$E=mc^2$`、`$\frac{a}{b}$`），自动排版为数学公式
- `Ctrl` + 点击多选，批量删除 / 移动 / 着色
- `Ctrl+C / X / V` 复制、剪切、粘贴整棵子树
- 撤销 / 重做（`Ctrl+Z` / `Ctrl+Shift+Z`，最多 100 步）
- 节点展开 / 收起：点击 `−/+` 按钮，空格或 `[` `]` 快捷键，工具栏一键展开/收起全部

### 布局方向
- 工具栏可切换布局方向：右向（默认，全部节点在右侧）、左向（镜像）、左右均衡（根节点子节点两侧交替排布）

### 画布外观
- 背景色：工具栏取色器可自定义画布背景色，一键恢复主题色；持久化并跟随导出
- 连线层级配色：工具栏可切换连线配色方案（默认单色 / 彩虹 / 冷色 / 暖色 / 莫兰迪 / 黑白灰），不同层级的连线自动使用不同颜色，层级超过配色数量后循环；持久化并跟随导出

### 大纲视图
- 左侧大纲面板与思绪图双向联动：点击定位、双击改名、`+` 加子节点、`✕` 删除、箭头同步展开状态

### Markdown 导入 / 导出
- 支持缩进列表（`- * + 数字`）、`#` 标题、`[文字](链接)`、`![图](data:…)`、`> 备注`

### 节点增强
- 图片：右键 → 添加图片（本地文件，base64 内嵌，≤2MB）
- 链接：节点右上角 ↗ 图标，点击新标签打开
- 备注：侧边备注面板或右键 → 备注，支持多行
- 着色：右键 → 着色，12 种颜色或恢复主题色
- 样式：工具栏「样式」面板，选中节点可自定义背景色 / 文字颜色 / 边框颜色与粗细 / 圆角 / 字号 / 加粗，实时预览、批量应用到选中节点，随 JSON 持久化并跟随导出

### 节点关联（关系连线）
- 右键节点 → 建立关联，再点击另一个节点完成连线（带箭头，Esc 取消，支持实时预览）
- 点击关联线选中，右键关联线可：编辑注释（显示在连线上）、删除关联、反转方向
- 关联注释标签：点击标签直接编辑，拖拽可沿线移动位置（随 JSON 持久化）
- 选中关联线后按 Delete 删除；删除节点时自动清理关联
- 关联随 JSON 导出 / 导入持久化，撤销重做、复制粘贴子树均保留关联
- 导出的 PNG / JPEG / SVG / PDF 均包含关联线与注释（Markdown 大纲不支持关联）

### 外框（分组框）
- `Ctrl` + 点击多选节点后，右键 → 添加外框（N 个节点）；单选节点也可添加外框，对相同选择再次操作即可移除外框
- 已在框内的节点右键菜单额外提供「移除外框」；重复添加或完全被现有外框覆盖的组合会被拒绝（嵌套除外）
- 外框成员须属于同一分支：同层兄弟节点，或同一父子链上的节点（非法组合会提示）
- 点击外框边框选中，可编辑标签（标签外露 14px 骑在框上方）或删除外框
- 外框支持多层嵌套：嵌套框与外侧框的边框之间保持固定间隔（14px），带标签的内层框其标签高度计入外层间隔，互不相交
- 外框与节点、其他外框自动避让：相邻外框按间距自动撑开布局
- 外框随 JSON 持久化，撤销重做、复制粘贴子树均保留；PNG / JPEG / SVG / PDF 导出均包含外框与标签

### LaTeX 公式
- 在节点文字任意位置书写 `$...$`，提交编辑后渲染为公式（编辑框中保留原始 `$...$` 文本）
- 由内置 KaTeX（v0.18，本地 `vendor/katex/`，离线可用）渲染，完整支持分式、根号、上下标、希腊字母、运算符、`\text{}` 等 LaTeX 语法
- 公式参与节点尺寸计算与自动换行（公式本身不会被折行截断），字体加载完成后自动重排校准尺寸，导出 PNG / SVG / PDF 均含公式

### 模板库
- 首次打开显示欢迎界面，可从 5 套内置模板快速开始：示例、会议纪要、读书笔记、项目规划、头脑风暴
- 应用模板会替换当前画布内容（原内容可通过撤销恢复）

### 主题
内置 6 套主题：经典蓝、清新绿、日落暖色、深色夜间、简约黑白、莫兰迪。选择后立即生效并持久化，导出效果跟随主题。

### 导出
| 格式 | 说明 |
|---|---|
| PNG / JPEG | 1x / 2x / 3x 分辨率可选，背景可选主题色 / 白色 / 透明 |
| SVG | 矢量格式，可无限缩放 |
| PDF | 单页海报式（按内容尺寸）或 A4 分页打印版（多页） |

导出内容跟随当前主题与展开状态。注意：远程 URL 图片无法保证进入导出文件，建议使用本地图片。

### 数据持久化
- 自动保存到浏览器 localStorage（每次编辑后 400ms 防抖）
- 工具栏"导入 / 导出"JSON 文件备份（localStorage 约 5MB 限额，大图请定期导出 JSON）

### PWA
通过 HTTP 访问时可"添加到主屏幕"，像 App 一样离线使用（Service Worker 缓存全部静态资源）。

## 测试

使用 Node.js 内置测试运行器（需 Node ≥ 18，零依赖）：

```bash
npm test
```

覆盖数据模型（增删改 / 撤销重做 / 剪贴板 / 关联 / 外框 / 分组 / 序列化）、布局（换行 / 截断 / 树形与自由布局 / 外框间距）、LaTeX 解析、Markdown 导入导出、搜索、存储与模板库。测试通过 VM 沙箱模拟浏览器环境运行（`test/helpers/shim.js`）。

## 项目结构

```
├── index.html            应用入口
├── manifest.webmanifest  PWA 清单
├── sw.js                 Service Worker（离线缓存）
├── icon-192/512.png      应用图标（tools/gen-icons.js 生成）
├── css/style.css         样式 + 6 套主题变量
├── vendor/katex/         KaTeX 0.18 本地资源（katex.min.js / katex.min.css / fonts）
├── js/
│   ├── model.js          数据模型、外框（frames）、撤销重做、剪贴板、模板库（applyTemplate）
│   ├── math.js           LaTeX 公式适配层（KaTeX 渲染 + 尺寸测量 + 兜底排版）
│   ├── layout.js         树形 / 自由布局算法（外框感知间距，含公式感知的自动换行）
│   ├── render.js         SVG 渲染（内联样式，可直接用于导出）
│   ├── editor.js         指针 / 键盘 / 拖拽 / 右键菜单
│   ├── search.js         搜索定位
│   ├── outline.js        大纲视图
│   ├── notes.js          备注面板
│   ├── markdown.js       Markdown 导入导出
│   ├── exporter.js       PNG/JPEG/SVG/PDF 导出（原生 PDF 写入）
│   ├── storage.js        localStorage + JSON 存取
│   └── app.js            工具栏 / 对话框 / 初始化
├── test/                 Node 测试（node --test）
│   ├── helpers/shim.js   浏览器环境沙箱
│   └── *.test.js         各模块测试
└── tools/gen-icons.js    图标生成脚本
```
