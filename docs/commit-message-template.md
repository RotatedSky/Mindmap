# Mindmap 提交规范 / commit message 模板
# =====================================================================
# 本文件既是说明文档，也是 git 模板：已配置为仓库 commit.template，
# 执行 git commit 时自动载入；以 # 开头的行会被 git 忽略，无需删除。
#
# 用法：
#   1. 填写第一行 <TYPE> 与 <摘要>（中文，≤50 字符）
#   2. 分条列出改动说明
#   3. 填写末行 TEST 验证说明（必填）
#   4. 保存并关闭编辑器即完成提交
#
# 类型前缀：
#   NEW  新功能        ENH  增强改进      FIX  缺陷修复
#   DOC  文档          REF  重构
# 仅在完成测试与验证后提交；TEST 行必填。
# =====================================================================

<TYPE>: <摘要>

- <改动说明，分条列出>
- ...

TEST: <验证说明（如：npm test 114/114 通过；新增 test/xxx.test.js N 项；浏览器冒烟验证）>
